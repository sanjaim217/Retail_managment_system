# 🏬 Retail Management System

A full-stack web application developed using **PHP & MySQL** to manage retail store operations efficiently.

---

## 📌 Project Overview

This system helps retail shop owners manage:
- Products
- Inventory
- Billing
- Users

It provides a simple and secure interface for daily retail operations.

---

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Server:** XAMPP (Apache)

---

## ✨ Features

- User authentication (Admin)
- Product management (Add / Update / Delete)
- Inventory tracking
- Billing & invoice generation
- Database-driven operations

---

- Login page
- Dashboard
- Billing page
